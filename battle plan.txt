2. PERFORMANCE: THE TECHNICAL NON-NEGOTIABLES
In 2026, performance is a design constraint, not an afterthought . Google uses AI to measure your speed; slow sites get filtered from AI Overviews .
Core Web Vitals Targets (Non-Negotiable)
Table
Metric	Target	Why It Matters
LCP	< 2.5s mobile	53% of mobile users abandon after 3s 
INP	< 150ms	Interactivity standard; 200ms is the fail line 
CLS	< 0.1	Layout shifts kill trust and rankings 
TTFB	< 600ms	Server response is the foundation 
Implementation Checklist (In Order of Impact)
1. Image Optimization (Biggest Bang for Buck)
Convert ALL images to WebP/AVIF format
Implement responsive images with srcset
Add explicit width/height to prevent layout shifts
Lazy load everything below the fold
Compress hero images to 70-80% quality for mobile 
2. JavaScript Discipline
Defer or async all non-critical scripts
Remove unused JS — most sites carry 50-70% dead CSS/JS weight
Break up long tasks (>50ms) to optimize INP
Reduce DOM size to <1,500 elements 
3. CSS Optimization
Extract critical above-the-fold CSS and inline it
Load remaining stylesheets asynchronously
Strip unused CSS rules
Use font-display: optional to prevent FOIT/FOUT 
4. Server & CDN
Enable full-page caching (watch out for dynamic content bypasses)
Use a CDN with Indian edge servers (Cloudflare, AWS CloudFront Mumbai)
Enable Brotli compression and proper cache headers
If TTFB >600ms, change hosting immediately 
5. Third-Party Script Audit
List every external resource
Remove anything non-essential (social widgets, chatbots, analytics bloat)
If you must use ads, reserve static ad slots to prevent CLS 
6. Monitoring
Set up Google Search Console Core Web Vitals report
Test on real mobile devices with network throttling (not just your MacBook)
Monitor monthly — performance degrades naturally over time

5. AESTHETICS: DESIGN THAT CONVERTS
Design Principles for 2026
1. Performance-First Minimalism
Every element earns its place
White space guides the eye to critical information
No decorative elements that don't contribute to understanding or action 
2. Mobile-First (Because 88% of India Is Mobile)
Design for thumb-friendly navigation (tappable elements in lower half of screen)
Sticky menus, collapsible sections
Tap targets minimum 44x44 pixels with 8px spacing 
Hero images: 800x1200px for mobile; blog images: 640x320px 
3. Bold Typography
Oversized headlines that communicate before the user reads
Limited font palette (2 fonts max)
High contrast for readability
Text communicates faster than images on news sites 
4. Dark Mode Standard
Toggle between light/dark themes
Reduces eye strain, saves battery on OLED
Expected by 2026 users 
5. Micro-Interactions (Lightweight Only)
Subtle hover effects, loading animations
Must not impact performance
Provide motion reduction options for accessibility 
6. Accessibility (WCAG 2.1 AA Minimum)
Semantic HTML for screen readers
Keyboard navigation for all interactive elements
Color contrast meeting readability standards
Alt text for all images 
What NOT To Do
❌ Video backgrounds (kills performance)
❌ 3D elements (unless absolutely necessary)
❌ Heavy parallax scrolling (confuses mobile users)
❌ Pop-ups and interstitials (Google penalizes, users hate)
❌ Auto-playing anything
