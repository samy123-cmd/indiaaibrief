```
Sitemap: https://indiaaibrief.com/news-sitemap.xml
```
- Verify no other routes are blocked accidentally
- Ensure sitemap URLs are absolute and HTTPS

### 1.2 Sitemap Architecture
Create THREE sitemap files:

**A. Main Sitemap (`/app/sitemap.ts`)**
- Dynamic generation using Next.js sitemap.ts convention
- Include: homepage, all category pages, all article pages, all product pages, all static pages
- For articles: use `lastmod` from `modifiedAt` or `publishedAt` frontmatter
- `changefreq`: homepage=daily, news articles=daily, explainers=weekly, playbooks=monthly, static pages=monthly
- `priority`: homepage=1.0, category pages=0.8, articles=0.6, product pages=0.7, static pages=0.5
- Max 50,000 URLs per sitemap. If exceeded, create sitemap index.
- Validate XML structure: proper `<urlset>`, `<url>`, `<loc>`, `<lastmod>`, `<changefreq>`, `<priority>` tags

**B. News Sitemap (`/app/news-sitemap.ts`)**
- Google News specific format
- Include ONLY articles from last 48 hours
- Required tags: `<news:name>IndiaAIBrief</news:name>`, `<news:language>en</news:language>`, `<news:publication_date>` (ISO 8601), `<news:title>`
- Update every time a news article is published
- Submit separately to Google Search Console

**C. Image Sitemap (Optional but Recommended)**
- Include all article hero images
- Tags: `<image:loc>`, `<image:title>`, `<image:caption>`

### 1.3 Canonical URLs
- EVERY page must have a self-referencing canonical tag
- For paginated pages: `/news?page=2` should canonical to itself (NOT the first page)
- For filtered/sorted pages: canonical to the base category page if filters are not SEO-significant
- For product pages with query params: canonical to clean URL without params
- Use `next/head` or metadata API to inject `<link rel="canonical" href="absolute-url" />`
- No trailing slash inconsistencies — pick one and 301 redirect the other

### 1.4 Pagination SEO
- Category listing pages: implement proper pagination
- Use `rel="prev"` and `rel="next"` in head (if using traditional pagination)
- OR use infinite scroll with proper URL-based pagination fallback for crawlers
- Pagination URLs: `?page=2`, `?page=3` etc.
- Each paginated page must have unique title: `News — Page 2 | IndiaAIBrief`

### 1.5 Hreflang (If Applicable)
- If any content exists in Hindi or other Indian languages, implement hreflang
- `<link rel="alternate" hreflang="en-in" href="https://indiaaibrief.com/path" />`
- `<link rel="alternate" hreflang="hi-in" href="https://indiaaibrief.com/hi/path" />`
- `<link rel="alternate" hreflang="x-default" href="https://indiaaibrief.com/path" />`

### 1.6 URL Structure Final Audit
- All URLs lowercase
- Hyphens for spaces, NO underscores
- No special characters except hyphens
- No query params in canonical URLs (use clean slugs)
- Consistent trailing slash policy (recommend: NO trailing slash, 301 redirect trailing slash to non-trailing)
- 301 redirects for any changed URLs
- Custom 404 page returns proper 404 status code
- Custom 500 page returns proper 500 status code

- Target: < 2.0s
- Hero image must be: WebP/AVIF, properly sized, eager loaded, explicit dimensions
- Font loading: `font-display: optional`, preloaded weights only
- No render-blocking resources above the fold

- Target: < 150ms
- Break up long tasks (>50ms)
- Minimize DOM size (< 1500 elements)
- Use `content-visibility: auto` for below-fold sections

- Target: < 0.05
- ALL images must have explicit width and height
- ALL ads/embeds must have reserved static space

- No late-loading content pushing things around
- Use `aspect-ratio` CSS for responsive containers

- Target: < 400ms
- Edge caching at Mumbai (Vercel Edge)
- Database queries optimized (indexes, no N+1)
